1. Попередні умови Потрібен робочий кластер Kubernetes з kubectl та встановленим Metrics Server. 2. Створення Namespace kubectl apply -f .infrastructure/namespace.yml 3. Розгортання застосунку Використовуємо Guaranteed QoS та RollingUpdate для стабільності та оновлення без простоїв. kubectl apply -f .infrastructure/deployment.yml 4. Налаштування автомасштабування (HPA) HPA масштабує поди від 2 до 5 на основі використання CPU та RAM (70%). kubectl apply -f .infrastructure/hpa.yml 5. Доступ до застосунку Додайте сервіси для внутрішнього та зовнішнього доступу: kubectl apply -f .infrastructure/clusterip.yml kubectl apply -f .infrastructure/nodeport.yml Щоб дізнатися зовнішній порт: kubectl get services -n todoapp
